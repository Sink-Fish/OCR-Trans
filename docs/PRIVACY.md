# OCR Trans 隐私政策

适用于 OCR Trans 0.7.0，更新日期为 2026 年 11 月 23 日。

**截图和翻译。** OCR Trans 在你启动截图时读取屏幕画面，使用你选中的区域进行识字、翻译、钉图或标注。屏幕画面、识别文字、译文和术语表在设备上处理。使用这些功能无需注册账号。应用没有广告、跟踪或分析服务。

**本机记录。** 开启历史记录时，应用在当前用户的应用数据目录保存最近最多 50 次截图、识别文字和译文。你可以在「设置 → 常规」中关闭记录或设置保留期限，在「截图历史」中删除单条或清空全部。关闭历史后，已经保存的记录仍可手动删除。复制、导出图片或保存诊断文件会把相应内容写入你选择的位置或系统剪贴板。

**网络连接。** 按需下载识字或翻译模型时，应用向提供模型文件的服务（Hugging Face、所选镜像或 ModelScope）请求文件。服务及其内容分发网络可收到下载请求、IP 地址和客户端信息。请求不含截图、原文、译文或术语表。GitHub 分发版还会向 GitHub 请求公开版本信息，可在「设置 → 常规」关闭自动检查。Mac App Store 版通过商店获取应用更新。

**反馈与联系。** 诊断报告可在本机查看和导出。提交公开问题前，请检查附件和文字，移除个人信息。有关数据使用或删除的问题，请通过 [OCR Trans 支持入口](https://github.com/Sink-Fish/OCR-Trans/issues) 联系开发者。
