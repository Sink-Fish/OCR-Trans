# 图标来源与使用

应用图标、菜单栏图标和界面标记中的“文”取自 Adobe 思源黑体 Source Han Sans CN Bold 2.005，已转换为矢量路径。安装包使用渲染后的图形。字体软件采用 SIL Open Font License 1.1，保留字体名称为 Source。[上游版本](https://github.com/adobe-fonts/source-han-sans/releases/tag/2.005R) · [字体许可](../../scripts/notices/SourceHanSans-2.005-LICENSE.txt)

`logo-primary.svg` 是主图标，`logo-small.svg` 用于小尺寸图标，`tray-template.svg` 用于菜单栏，`logo-mark.svg` 是界面标记。可以从仓库根目录运行 `./scripts/build_icons.sh` 重新生成桌面图标。

非商业衍生版可以沿用图标，须明显标注“非官方修改版”及发布者。名称与图标的完整使用条件见[项目许可](../../LICENSE)。
