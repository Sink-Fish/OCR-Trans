# OCR Trans 使用手册（v0.6.6）

OCR Trans 是一个离线的截图识字 + 翻译小工具：按一个快捷键框选屏幕，就能翻译、识别文字、钉图、涂鸦、复制或保存——英文 / 日文会**直接在原位置替换成中文**，结果像便签一样钉在屏幕最上层，还能在上面画标注。

**所有识别和翻译都在你的电脑上完成，不联网、不上传任何截图或文字。** 只有在“模型管理”里主动下载模型时才会联网。

---

## 1. 安装

### macOS（13 Ventura 及以上，Apple 芯片）

1. 打开 `OCR-Trans_0.6.6_arm64.dmg`，把 **OCR Trans** 拖到“应用程序”文件夹。
2. 官方 Mac 安装包使用本地签名，未经 Apple 公证。首次打开可能出现开发者验证提示。确认文件来自官方发布页后，可按 macOS 在“系统设置 → 隐私与安全性”中提供的选项打开。
3. 首次截图时请授予屏幕录制权限。若系统要求重新打开应用，请按提示操作。
4. 打开后应用不会出现在程序坞（Dock）里，而是在**屏幕右上角菜单栏**出现一个“**框选 文**”图标（四个角框住一个“文”字），所有功能都从这里或快捷键进入。

### Windows

[0.6.6 发布页](https://github.com/Sink-Fish/OCR-Trans/releases/tag/v0.6.6)已提供 `OCR-Trans_0.6.6_native_x64-setup.exe`。安装包未签名，系统可能显示安全提示，请先核对官方发布页及 SHA-256。安装程序会检查 WebView2 和应用启动所需的 Microsoft Visual C++ 运行库，缺少时提示安装。若缺少 Visual C++ x64 运行库，请按提示从微软官方网站获取。

## 2. 第一次使用：授权“屏幕录制”

macOS 要求你手动允许应用读取屏幕内容，否则截图会失败或是一片空白。

1. 首次启动会弹出“**欢迎使用 OCR Trans**”引导窗口，第 1 步显示权限状态。
2. 点 **“打开系统设置授权”**，系统会打开 *系统设置 → 隐私与安全性 → 屏幕与系统音频录制*。
3. 在列表里打开 **OCR Trans** 的开关（列表里没有就点“+”添加）。
4. 回到引导窗口试一次截图。如果系统提示重启，可以点 **“我已授权，重启应用”**。
5. 引导窗口第 1 步显示“已授权”即可。点“开始使用”关闭引导。

以后想再检查：菜单栏图标 → **新手引导 / 权限检查…**。

> 如果之前授权过、又换了新版本应用，系统可能需要重新授权：在上面的列表里把 OCR Trans 关掉再打开，然后重启应用。

## 3. 截图：一个快捷键

默认快捷键 **⌥⇧O**（Windows：Alt+Shift+O），可在 *设置 → 常规 → 截图* 修改。

1. 按快捷键，屏幕“冻结”并变暗。
2. **按住鼠标左键拖动**框选区域，松开。
3. 选区旁边出现**操作栏**（可以先拖动选区边上的小圆点调整大小），点按钮或按单键：

| 按钮 | 数字键 | 字母键 | 作用 |
|---|---|---|---|
| 翻译 | **1** | T | 英文 / 日文在原位置变成中文，结果钉在原处 |
| 识字 | **2** | O | 打开**文字窗口**：在图上拖选文字、编辑、复制（见第 5 节）。默认不自动写剪贴板 |
| 钉图 | **3** | P | 把选区钉在屏幕最上层 |
| 标注 | **4** | D | 钉图并直接打开标注工具（画笔） |
| 复制 | **⌘C** | | 把选区图片复制到剪贴板，并关闭截图界面 |
| 保存 | **⌘S** | | 弹出系统保存窗口，选择位置和文件名保存为 PNG |
| 取消 | **Esc** | | 退出 |

- 操作栏按钮上标有数字 1–4；**回车**执行“默认动作”（*设置 → 常规 → 回车默认动作*：翻译 / 钉图 / 识字，默认翻译；操作栏里高亮的就是它）。
- 选好后选区四周有一圈细的薄荷绿边框（外侧带一道淡淡的深色描边，浅色背景上也看得清），四条边都完整显示，和钉图的边框一样；调整大小的小圆点是实心薄荷绿，短选区只在四个角显示圆点，不会挡住边框。
- 不满意选区，直接在别处重新拖一个即可。
- 多屏时，框选前把鼠标移到另一块屏幕，截图界面和键盘焦点会自动跟过去。开始拖选后，当前选区留在原来的屏幕。
- **Esc**、**右键**或提示条上的“取消”随时退出。
- **截图后自动翻译**（*设置 → 截图*，或新手引导里勾选）：打开后，松开鼠标就直接原位翻译并钉图，不再显示操作栏。

### 可选：直接动作快捷键
如果习惯以前“一个动作一个快捷键”，可以在 *设置 → 常规 → 截图 → 可选：直接动作快捷键* 里给“直接截图翻译 / 识字 / 钉图”各设一个（默认不设置）。它们框选后立即执行对应动作，不显示操作栏。菜单栏图标里也有这三项。

快捷键设置：点输入框，直接按下想要的组合键；按 Delete 清空，Esc 取消。若与其他软件冲突，设置页顶部会提示“注册失败”，换一个即可。

> 从 0.3 升级：原来的 ⌥⇧O 自动变成新的截图快捷键；原来默认的 ⌥⇧S / ⌥⇧T 被释放（变成可选、未设置）；如果你改过这些快捷键，自定义的会保留为直接动作快捷键。

## 4. 钉图窗口

翻译 / 钉图 / 涂鸦的结果都会以“钉图”形式出现在原来的位置，永远在最上层，可以同时钉很多张。每张钉图四周都有一圈和选区一样的薄荷绿边框（外侧带淡淡的深色描边），上下左右四条边粗细相同，白色或浅绿色背景上也看得清。

### 基本操作
| 操作 | 方式 |
|---|---|
| 移动 | 选“✥ 移动”工具时按住拖动 |
| 缩放 | 鼠标**滚轮**（20%–500%） |
| 透明度 | **⌥ / ⌘ + 滚轮**（Windows：**Alt + 滚轮**），或点工具栏 **⋯** 选 100% / 80% / 60% / 40%。Ctrl + 滚轮和触控板双指捏合是缩放 |
| 原文 ⇄ 译文 | 按 **T** 或**空格**，或点工具栏“翻译 / 原文” |
| 关闭 | **Esc**，或在空白处**双击**，或点工具栏最右的 × |
| 文字 | 工具栏“识字”打开同一个**文字窗口**（正在看译文就打开译文，见第 5 节） |
| 复制图片 | **⌘C** 或图片按钮（包含标注和译文） |
| 保存图片 | **⌘S** 或下载按钮，保存为 PNG |
| 关闭所有钉图 | 菜单栏图标 → 关闭所有钉图 |

工具栏在鼠标移到钉图上时显示，移开后自动淡出。工具栏会自动放在钉图下方；下方放不下时放到上方，上下都放不下时放在钉图内部，并且始终完整显示在当前屏幕里（不会被屏幕边缘、菜单栏或程序坞挡住）。

工具栏平时只有一行：移动 · **标注** · 翻译 / 原文 · 识字 · 复制图片 · 保存 · **⋯ 更多**（透明度、切换翻译引擎）· 关闭。点“标注”展开第二行标注工具；颜色和粗细收在一个色块按钮里，矩形 / 椭圆 / 箭头收在一个形状按钮里，点开后在下面一行选择。

### 看原文、改译文
- 在译文状态下，**鼠标停在某段译文上**，会浮出这一段的**原文**。
- **双击某段译文**可以直接修改，回车保存，Esc 放弃。改过的译文也会同步到历史记录。

### 翻译引擎切换
工具栏 **⋯ 更多** 里的“高质量重译 / 改用快速翻译”：用另一种引擎重新翻译这张图（见第 7 节）。

## 5. 文字窗口（识字）

框选后按 **2**（或点“识字”）、直接识字快捷键、钉图工具栏上的“识字”按钮，打开的都是**同一个文字窗口**。同一张截图重复打开时，会回到已经打开的那个窗口。

- **左边 / 上边是截图**，识别出的文字像 macOS“实况文本”一样叠在图上：鼠标移上去会淡淡标出文字所在的位置，**按住拖动**就能跨字、跨行选择，**双击**选中一整行。
- **右边 / 下边是全部文字**，可以直接修改。在图上选中的部分会同步高亮在文字框里；在文字框里选中，图上也会同步高亮。
- **⌘C**：只复制选中的文字；什么都没选时复制全部。
- **一键复制全部**：复制文字框里的全部内容（包括你改过的），窗口里会提示“已复制”。
- **复制并关闭**（**⌘↩**）：复制全部并关闭窗口。
- 顶部 **原文 / 译文**：切换到译文（首次切换时翻译），译文同样可以编辑和复制；在图上拖选会切回原文。
- 改过原文后，暂停图上的文字选择，避免复制修改前的旧文字；此时在文字框选择、编辑和复制，点状态栏里的“还原”可恢复图上选择。
- **钉图**：把这张截图钉到屏幕上；**Esc** 关闭窗口。

**识字不会再悄悄覆盖剪贴板**：默认只有你点“复制”或按 ⌘C 时才写入剪贴板。想要以前“识别完自动复制全部”的行为，打开 *设置 → 常规 → 识字后自动复制全部*。

## 6. 标注工具

点工具栏的“**标注**”打开第二行工具：

| 顺序 | 工具 | 用法 |
|---|---|---|
| 1 | 移动 | 拖动钉图（默认工具） |
| 2 | 选择 | 点击已有标注选中（蓝色虚线框），**拖动移动**，**Delete / Backspace** 或垃圾桶按钮删除 |
| 3 | 画笔 | 自由画线 |
| 4 | 荧光笔 | 半透明粗笔，盖在文字上仍能看清 |
| 5 | 形状 ▾ | 矩形 / 椭圆 / 箭头，点小箭头在下一行切换 |
| 8 | 文字 | 点击位置后输入，回车确认（Shift+回车换行） |
| 9 | 序号 | 每点一次放一个圆形序号，**自动递增** ①②③… |
| 10 | 马赛克 | 拖出区域打码 |

- **颜色与粗细**：点色块按钮，下一行选 5 个常用色、自定义取色器和细 / 中 / 粗（粗细也影响文字、序号、马赛克的大小）。
- **撤销 ⌘Z**、**重做 ⌘⇧Z（或 ⌘Y）**，最多 100 步；移动和删除也能撤销。
- 复制 / 保存图片时，标注会一起导出。

## 7. 翻译引擎

| 引擎 | 模型 | 速度（本机实测） | 特点 |
|---|---|---|---|
| **快速**（默认） | 英→中：OPUS-MT；日→中：M2M100 | 0.1–0.5 秒 | 小巧，界面短语、说明文字效果不错；长句偶尔生硬 |
| **高质量**（可选） | Qwen3-1.7B 大模型 | 随硬件与文本量变化；本次 Mac 4 段翻译约 1.8 秒，首次加载另需数秒 | 结合屏幕上下文翻译，长文分片；通常语气更自然、用词更统一，但仍可能误译 |

- 默认引擎在 *设置 → 翻译 → 默认翻译引擎* 里选。
- 高质量引擎需要先在“模型”页下载（约 1.1 GB）。默认闲置 5 分钟后自动释放内存，可在设置中调整，下次使用时重新加载。
- 中文、无法识别语言的文字保持原样不翻译。

### 原位替换效果
翻译时会先把原文从图上“擦掉”（按周围背景补全，渐变背景也很自然），再用原文的颜色写上中文，字号自动适应原来的位置。背景是照片或复杂纹理时，会再垫一层半透明底板保证可读。

## 8. 术语表

*设置 → 翻译 → 术语表*，每行一条：

```
Pin = 钉图
Settings = 偏好设置
設定 = 设置
```

- 两种引擎都会遵守。
- 英文按**整词、不区分大小写**匹配（`pin` 不会匹配 `Pinned`）；日文 / 中文按原样匹配。
- 写完点输入框外面即自动保存；已经翻译过的钉图点“快 / 精”可重新翻译。
- 每行只按第一个分隔符拆分，译文可以含等号或箭头。缺少原文或译文的行会提示行号，修正后再保存；修改其他设置不会清空未保存的术语草稿。

## 9. 截图历史

菜单栏图标 → **截图历史…**

- 自动保存最近 **50** 次截图（缩略图、时间、尺寸、识别文字、译文），超出后自动删除最旧的。
- **钉图**：在原来的屏幕位置重新钉出来（也可以双击缩略图）；**翻译**：重新钉出并翻译；**复制**：复制译文（没有则复制原文）；✕ 删除单条；右上角 **清空历史**（会再确认一次）。
- 历史保存在本机：`~/Library/Application Support/com.sinkfish.ocrtrans/history/`，只有你的账户能读取（0.5.6 起）。截图里可能有密码、聊天记录等，不想留记录可以在 *设置 → 常规 → 系统 → 保存截图历史* 关掉（关掉后不再记录新的截图，已有的在这里清空）。

## 10. 模型管理

*设置 → 模型*（或菜单栏图标 → 模型管理…）

| 模型 | 用途 | 大小 | 是否自带 |
|---|---|---|---|
| PP-OCRv5 文字识别 | 识字（中 / 英 / 日） | 约 21 MB | ✅ 应用自带 |
| 英→中 翻译（OPUS-MT） | 快速翻译英文 | 约 80–160 MB | ✅ 应用自带 |
| 日→中 翻译（M2M100） | 翻译日文 | 约 0.5–1 GB | 需下载 |
| 高质量翻译（Qwen3-1.7B） | 高质量引擎 | 约 1.1 GB | 需下载 |

- **下载**：显示进度，可取消；下载到 `~/Library/Application Support/com.sinkfish.ocrtrans/models/`。
- **下载源**：*设置 → 常规 → 下载源*。默认“自动”（先 huggingface.co，失败时用国内镜像 hf-mirror.com）；国内网络可直接选 **hf-mirror.com**。
- 下载的是固定版本的文件；按下载清单核对大小和 SHA-256。校验不符会丢弃并报错。网络 30 秒没有进展会自动失败，“自动”模式下接着换镜像；下载中随时可以点“取消”。
- **自定义模型文件夹**：已有模型（例如项目里的 `models/`）可在 *设置 → 常规 → 自定义模型文件夹* 指定，不用重复下载。
- **删除**：只能删除下载目录里的模型，应用自带的不能删。

## 11. 其他设置

- **识字后自动复制全部**：*设置 → 常规*。默认关闭——识字只在你点复制或按 ⌘C 时才写剪贴板；打开后识别完立即复制全部文字（0.5.2 及以前的行为）。
- **登录时自动启动**：*设置 → 常规*（或引导窗口）勾选。默认关闭。
- **译文字体**：*设置 → 显示 → 译文字体*，填 CSS 字体名（默认苹方 / 微软雅黑）。
- 设置保存在 `~/Library/Application Support/com.sinkfish.ocrtrans/settings.json`（Mac 上 config 目录）。

## 12. 常见问题

**按快捷键没反应**
- macOS 26 可以单独控制每个应用的菜单栏图标。到 **系统设置 → 菜单栏 → 允许在菜单栏中显示** 检查 **OCR Trans**。从访达打开安装好的应用；在终端可用 `open -a "OCR Trans"`。
- 如果菜单栏找不到 OCR Trans 图标（四角框住“文”），在“应用程序”中重新打开 OCR Trans。已运行的应用会重新连接菜单栏，并打开设置。
- 菜单栏图标 → **修复快捷键**，然后再试。不需要退出应用或关闭已有钉图；恢复失败会显示原因。应用也会在检测到休眠或长时间调度暂停后自动重新注册。
- 快捷键可能被其他软件占用：*设置 → 常规* 换一个组合，看顶部是否提示“注册失败”。
- 也可以点菜单栏图标 → 截图…，确认功能本身正常。

**截图是黑的 / 空白 / 提示需要屏幕录制权限**
- 如果提示 macOS 未允许此次截图，请按第 2 节检查授权，回到应用重试。

**截图界面出现后又取消**

- 看提示里是哪个应用切到了前台。如果按同一个快捷键时另一款截图工具也启动了，可以在 OCR Trans 的“设置 → 常规”中更换组合键。
- 如果前台出现 macOS 的权限对话框，请先处理对话框，再按截图快捷键。

**识别不出文字 / 文字很少**
- 选区太小或文字太小（小于约 8 像素）时效果差，可以先放大页面再截图。
- 竖排文字能识别，但译文会横排显示。

**提示“未安装…翻译模型”**
- 日文需要下载 M2M100；高质量引擎需要下载 Qwen3。见第 10 节。

**模型下载失败**
- 换下载源为 hf-mirror.com 再试；公司网络可能拦截大文件下载。
- 提示“校验失败”或“大小不对”：通常是代理或镜像返回了错误页面，换个下载源再试。

**高质量翻译第一次很慢**
- 首次需要把 1.1 GB 模型加载进内存（几秒，钉图上会显示“正在加载高质量翻译模型…”）。闲置 5 分钟后自动释放内存（*设置 → 翻译* 可改成 1 / 10 / 30 分钟或不释放），再用时重新加载。
- Mac 用 Metal，每屏通常 1–5 秒。Windows 有可用显卡（集成或独立）时自动用显卡（Vulkan），否则用处理器；在 *设置 → 翻译 → 高质量翻译使用* 下面能看到当前用的是什么。显卡出错会自动改用处理器并记住，可点“重新尝试显卡”。
- 文字很多时会分段翻译；某些段落超时或没译好，会尝试用快速翻译补上并提示“N 段已用快速翻译”。缺少快速模型、推理失败或仍超过输出上限时会警告并保留原文，避免误把截断内容当作完整译文。

**译文盖住的地方有色块 / 底板**
- 背景是照片或复杂纹理时会加半透明底板，这是为了保证可读；按 T 可随时看原文。

**应用出错了**
- 错误日志在 `~/Library/Logs/com.sinkfish.ocrtrans/ocr-trans.log`，反馈前请先预览并删除个人路径或其他敏感内容。

## 13. 兼容性

- 不同缩放比例的多显示器可能影响选区定位。反馈时请注明显示器排列、各屏缩放比例和截图所在屏幕。
- Windows 高质量翻译的显卡加速取决于 Vulkan 驱动，也可以在设置中选择 CPU。
- 更新版本请从官方发布页下载。更新前可以保留已有的模型目录。

## 14. 翻译与历史恢复


- 钉图或识字窗口翻译期间可以查看阶段与用时，点击“取消”停止当前翻译。高质量模型运行在辅助进程中，退出或超时时由主程序处理，并在适用时改用快速翻译。
- 历史索引出现异常时，在截图历史中选择“恢复历史索引”。备份中有记录的截图会保留文字与译文，其他可读 PNG 可恢复为图片记录。设置中可选择历史保留天数及容量，保存下一张截图时执行清理。
- 在“设置 → 模型”点击“校验文件”可核对发布清单。自定义模型可能与清单不同，请按来源判断是否需要重新下载。
- 在“设置 → 关于 → 运行诊断”可预览、复制或保存诊断文本。
